# MLBB Account Checker

## Run on Windows
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `py -m pip install -r requirements.txt`.
4. Run `py app.py`.
5. Visit http://127.0.0.1:5000.

This is an unofficial Flask project using a community third-party lookup endpoint, not an official Moonton API. Username and level depend on what the service returns. Account creation date is shown as Unavailable if the service does not provide it. Never provide passwords or OTPs.
